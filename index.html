Tools

Quick calculators for everyday office work.

Calculator

Add, subtract, multiply, divide, parentheses. Paste numbers with commas, × and ÷ both work. Enter keeps the line on the tape below — click any tape result to drop it back into the expression, or copy it.

Quadrant bearing ↔ azimuth

Type in either box — the other converts live. Accepts 45°30'15", 45 30 15, or decimal 45.5042.

Bearing add / subtract

DMS or decimal. Result normalizes to 0–360°; the raw value shows underneath for miscloses.

Feet ↔ metres

International foot (0.3048 m). Decimal feet, not ft-in.

Feet-inches ↔ metres

Type it as the plan writes it — 12' 6 1/2", 12-6, 6 1/2" (inches only), or a plain number for feet. Add an m to go the other way — 3.81 m shows 12' 6" (to the nearest 1/8"; ≈ when not exact).

Area converter

Type into any box — the other three fill in. 1 acre = 43,560 sq. ft.; 1 ha = 10,000 m².

Invert calculator

unit of the drawing / rim value
Depth (m)Top of pipe?Size (m)Invert elev.
Everything in metres: depths as booked, pipe size too (a 300 mm culvert is 0.3, a 150 is 0.15). Invert = rim − depth (− pipe size when measured to top of pipe). Results show in metres and feet.

Proration

Enter the plan (record) calls and the measured field distance — the factor derives from field ÷ Σ plan and every call prorates, with a Σ check that the prorated calls rebuild the field. Or type a factor directly (Helmerts, combined scale) to apply it; the field box then shows the implied distance. Enter on the last call adds a row.

Absolute accuracy (95%)

Accuracy = 1.96 × √(σN² + σE²) — horizontal, 95% confidence. The governing (largest) value is highlighted; that's the one for the accuracy statement.

Combined scale factor

Use only with coordinates from corrected dual-frequency network RTK observations (or better). Autonomous or uncorrected positions are not a valid basis for a scale factor entering the calc record.

UTM on GRS80: grid factor from the easting's offset to the 500 000 m central meridian at the latitude implied by the northing; elevation factor R/(R+h) with h = H + geoid separation. Matches NRCan/mascot output to 8 decimals. The combined factor drops straight into the proration card's factor box.

    Workflow notes

    Arch PDF → CAD (MicroSurvey). Vector arch PDFs only — run PDFIMPORT, pick the page or attached underlay, then immediately SCALE with the Reference option off one labelled dimension and verify against a second dimension elsewhere on the sheet before coordinating anything. Keep imported linework on its own layer set; it is reference geometry only — measurements are held as measured. If PDFIMPORT returns nothing useful, the PDF is a scan: chase the CAD file, don't trace pixels.
